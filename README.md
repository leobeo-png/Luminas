## Description
 - Custom keyboard NKRO HID 
 - PCB size for 15.6" laptop
 - ToF sensors instead of IR for compactness
---
## Components Used:
 - Arduino Pro Micro
 - MPR121 Modules x3
 - VL53L0X ToF sensors x2 
 - TCA9548 I2C Multiplexer
 - Pull-up resistors
