## Description
 - Custom keyboard NKRO HID 
 - PCB size for 15.6" laptop
 - Separate I2C Bus for the capacitive touch and time of flight to reduce load
---
## Components Used:
 - STM32F411CEU6
 - MPR121 Modules x3
 - VL53L0X ToF sensors x2 (x4 in the future)
 - TCA9548 I2C Multiplexer
 - Pull-up resistors
